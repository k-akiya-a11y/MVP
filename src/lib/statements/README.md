# src/lib/statements

銀行・カード明細 CSV の読取と取込。形式（列の見出し・文字コード）は `formats.ts` に銀行・カード会社ごとに足します。1行でも読めない行があればファイル全体を取り込みません。CSV の書式が壊れているとき（閉じられていないクオート、値の途中のクオート、閉じクオートの後ろの余分な文字）や、行の列数が合わないとき（途中で切れた行、見出しより右に値がある行）も、読めた行だけを取り込まず、行番号つきの失敗として記録します。

重複キー（口座・日付・入出金・金額・摘要・残高・同一内容の連番）はファイルごとに連番を数え直すので、キーが同じでも同一取引とは限りません。取込済みと同じキーの行を読み飛ばすのは、取込全体が同じ内容の再実行だと DB が確かめられたときの残高のある行だけで、それ以外は「重複の疑い」として人の確認に回します。DB への登録は `import_bank_statement`（担当者の権限、RLS あり）で行い、外部への書込はしません。
