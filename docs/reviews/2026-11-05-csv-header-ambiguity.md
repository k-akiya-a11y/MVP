# CSV 見出しの列が曖昧なとき、最初の列だけを使い他を黙って無視する: 実装前の期待記録

作成: 2026-11-05（コード・テストを書く前の期待の記録。実装後にこの節を書き直さない。期待が誤っていた場合は末尾に日時と理由を追記する）。

## 目的

`locateHeader`（`src/lib/statements/parse.ts:48-73`）は、意味ごと（日付・摘要・出金・入金・符号付き金額・残高）に、見出し候補を先頭から順に探し、**最初に見つかった列だけ**を使う。同じ意味の列が見出しに2つ以上あっても、2つ目以降は黙って無視される。

Codex が実際の `parseStatementCsv` で再現した結果（Claude は実行していない）:

- 銀行形式の入力 `日付,摘要,出金,出金額,入金\n2026/11/01,架空支払,,1200,`
  - 「出金」(3列目) が使われ、「出金額」(4列目) の 1200 は無視される。
  - 出金・入金とも空 = 金額0と読まれ、`rows: []`、`errors: []`、`ignored` に「金額が0」の1件。エラーなしで、明細が黙って捨てられる。
- 日付・摘要・符号付き金額・残高の別名が重複していても、同様に先頭の列だけが使われ、別の列の値を読み違える。

「明細を黙って捨てない」「元明細と処理結果の件数・金額を照合する」（`docs/development-rules.md`）に反する。

## 期待する動作

1. 意味ごとの対応列は、見出し行の中で**物理的に異なる列が高々1つ**でなければならない。
2. 同じ意味に対応する物理列が2つ以上ある見出しは、行を1行も解釈する前に、ファイル全体を失敗にする（`rows: []`、`ignored: []`、`errors` に理由）。
3. 判定は、正規化（NFKC + 空白除去、既存の `normalizeHeader`）後の見出しで行う。全角・空白違いの別名も重複として検出する。
4. 同じ物理列が、形式の複数の別名に一致しても（例: 別名リストに正規化後同じになる文字列が複数ある）、曖昧ではない。**異なる物理列を数える**。
5. エラーの行番号は、実際に見出しとして選ばれた行の CSV 上の物理行番号（前置きの行・クオート内改行があっても `csvRows[headerIndex].line`）。1行目固定にしない。
6. 文言は日本語で、どの意味が、どの見出し（列番号つき）で重複したかが分かること。例: `「出金」の列が複数あります（3列目「出金」、4列目「出金額」）。どれを使うか判断できないため取り込めません`。
7. 曖昧な意味が複数あれば、それぞれ1件ずつエラーにする（同じ見出し行の行番号）。
8. 見出し行の選び方（先頭10行のうち、日付と摘要が1つ以上ある最初の行）は変えない。重複の判定は選ばれた行にだけ行い、それ以前や以後の行は見ない。
9. 取込（`importStatementCsv`）は既存どおり `errors` が1件でもあれば `importRows` を呼ばず、`recordFailure` に行番号つきの理由と `sourceRowCount`（見出し行より後の空でない行数）を渡す。

## 架空の具体例

| 入力 | 期待 |
| --- | --- |
| `日付,摘要,出金,出金額,入金` + `2026/11/01,架空支払,,1200,` | 見出し行(1行目)で「出金」重複のエラー。`rows`/`ignored` は空。`importRows` は呼ばれない |
| `日付,摘要,出金,入金,残高,差引残高`（銀行） | 「残高」重複 |
| `日付,取引日,摘要,出金,入金`（銀行） | 「日付」重複 |
| `日付,摘要,内容,出金,入金`（銀行） | 「摘要」重複 |
| `利用日,利用店名,利用金額,金額`（カード） | 符号付き金額の重複 |
| `利用日,日付,利用店名,利用金額`（カード） | 日付の重複 |
| `日 付,日付,…`、`出金,出　金,…`（空白・全角の違い） | 正規化後同じ見出しの2列も重複 |
| 3行の前置き + 4行目に見出し | エラーの行番号は4 |
| `日付,摘要,出金額,入金額,備考,備考` | 取り込める（無関係な列の重複は無視） |
| `取引日,お取引内容,お支払金額,お預り金額,差引残高` | 取り込める（別名を1列ずつ使う） |
| 別名が複数あるが物理列は1つ | 曖昧ではない |

## 実装方針（最小）

`parse.ts` の `locateHeader` だけを変更する。意味ごとに一致する物理列の添字を重複なしで集め、1つなら従来どおりその列、複数なら曖昧として見出し行の添字と一覧を返す。`parseStatementCsv` は、曖昧のときに行の解釈へ進まずエラーを返す。
