# 完成チェックリスト

[共有開発ルール](development-rules.md) に基づく判定用テンプレートです。未チェックの項目は実施済みを意味しません。対象 PR・コミットごとにコピーして使い、日時、環境、担当、証拠へのリンクを記録します。該当しない項目は理由と判断者を明記し、省略を成功として扱いません。

## 判定の区別

| 段階 | 意味 |
| --- | --- |
| 実装完了 | 合意した変更が実装され、受入条件に対応付いている。検証・公開の完了は意味しない |
| 検証完了 | 対象の最新コミットについて必要な検証と独立レビューを終え、証拠と制約を記録している |
| リリース承認済み | 検証結果・既知リスク・復旧手順を踏まえ、Ken が対象版と公開範囲を明示して承認している |

## 記録欄（PR ごとに記入）

- 対象 PR／コミット、記録日時、環境、実装者、レビュー担当:
- 受入条件と証拠の対応:
- 確認済み（証拠）／未確認（理由）／既知の問題（影響・対策・担当）:
- 停止・復旧手順書と検証記録:
- 段階別の判定と判断者、Ken のリリース承認記録:

未確認項目が残る場合は「検証完了」としません。対象外の判断やリスク受容は理由と承認者を記録し、未実施の検証を実施済みに変えません。

## 実装完了の確認

- [ ] 目的、対象外、受入条件、データ・権限への影響を明記し、変更が受入条件を満たしている。
- [ ] UI・業務ロジック・認証認可・DB・外部連携の責務が分離され、共通検証を再利用し、不要な書換えを含めていない。
- [ ] 不具合修正では修正前に失敗する回帰テスト、最小修正、根本原因の記録があり、影響データの修復を別作業として扱っている。

## 検証完了の確認

- [ ] 最新 head のコミット SHA を記録し、Codex の独立レビューと必要な指摘対応を終えている。更新後の差分も確認している。
- [ ] 同じ最新 SHA の CI・lint・型チェック・関連テストの結果を確認している。未実行や利用できないチェックを明示し、通過のためにテストを弱めていない。
- [ ] 別テナントの閲覧・更新・参照を、画面だけでなく API・DB でも拒否することを確認している。
- [ ] 未認証・権限不足・役割や本人 ID の偽装を拒否し、許可された本人だけが承認できることを確認している。
- [ ] 再取込・再試行・並行処理で二重計上せず、同日同額等の正当な類似取引は消えないことを確認している。
- [ ] 不正な明細や途中失敗を黙って落とさず、取込元と結果の件数・金額が照合できることを確認している。
- [ ] 監査履歴の変更・削除を拒否し、監査記録が失敗したときに履歴なしの確定が残らないことを確認している。
- [ ] 架空の顧客・明細・マスタを用い、実際の Supabase・Google ログイン・Claude API を接続した検証環境で、ログイン → CSV 取込 → 候補生成 → 承認／修正／保留 → 履歴確認を通している。
- [ ] Ken／管理者と担当者の別アカウントで許可・拒否を確認し、担当者が管理者専用の承認・修正等を実行できないこと、担当外顧客へアクセスできないことを確認している。
- [ ] 空 DB への全マイグレーション適用と、架空の既存データが入った旧版 DB のアップグレードを検証し、件数・金額・権限・履歴を照合している。適用済みマイグレーションを改変していない。
- [ ] ステージングと本番の分離を確認し、検証環境で停止・アプリロールバック・DB 復元を個別に演習している。復旧後の照合、再試行、再開条件まで記録している。
- [ ] 外部への書込はロールバックで取り消せないことを手順書に明記し、外部との照合・補正の判断手順を用意している。
- [ ] 認証情報・顧客情報の漏えいを点検し、依存関係の脆弱性と残るリスクを評価している。

実結合の具体的な操作は既存の [実結合の確認手順（PR #2 の確認済み参照版）](https://github.com/k-akiya-a11y/MVP/blob/4dc1857b4d8f6a937cc41b4845acb0b9b5672f12/docs/integration-check.md) を参照します。この参照は手順の存在を示すもので、検証成功の証拠ではありません。実施時には対象コミットとの差分を確認し、使用した手順の版を記録してください。

## リリース承認の確認

- [ ] 未確認事項と既知の問題、影響する利用者・データ、対策、残存リスクを開示している。
- [ ] 運用手順書に監視、障害時の停止判断、連絡担当、アプリのロールバック、DB 復元、復旧後の照合・再開条件を記載し、演習結果を添えている。
- [ ] Ken が対象コミット、公開環境・範囲、残存リスクを確認し、人による明示的なリリース承認を記録している。実装完了・CI 成功・AI レビューのみでは承認としない。

このチェックリストはリリースや外部操作の自動許可ではありません。freee への書込・メール送信はこの文書追加 PR の対象外であり、この文書から実行権限は生じません。
