## 確認中に見つかり、直したこと

- Vercel のビルド失敗（Framework Preset が Next.js にならない）: `vercel.json` に `"framework": "nextjs"` を追加（`78004ef`）
- 手順書: 環境変数の種類（Config・Secret）と対象ブランチ、Supabase の Project URL に `/rest/v1` を付けないことを追記（`b3ffcaa`、`3e88524`）
- 手順の注意: 担当者の登録 SQL は、登録する2人が一度ログインした後に実行する（ログイン前の人は登録されない）
